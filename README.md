# Chat Overlay — плагин чата Twitch для OBS Studio

Нативный плагин-источник для OBS Studio (Windows x64, OBS 28–33): рисует чат
Twitch прямо в сцене, с настройками шрифта, цветов, обводки, времени жизни
сообщений, смайлов BTTV/7TV и модерации.

> **Статус:** версия 1.0, исходники готовы, но бинарник ещё не собирался в этой
> среде (здесь нет MSVC и интернета для shell). Первый прогон GitHub Actions
> покажет, есть ли ошибки компиляции — их нужно будет поправить по логу.

```
┌──────────────────────────────┐
│  [бейдж] Nick: сообщение Kappa │   ← прозрачный фон, смайлы, цвет ника
│  [бейдж] Другой: текст         │
└──────────────────────────────┘
```

## Интеграция дизайна (StreamElements / Streamlabs)

Группа настроек **«Тема и импорт»** переносит оформление из сторонних сервисов:

- **готовые пресеты** (StreamElements-классика, пузырьки, тёмная панель, чистый);
- **файл темы** — экспорт оверлея StreamElements (JSON) либо `.css`/`.json`;
- **вставка CSS** прямо из StreamElements «Custom CSS» или темы Streamlabs.

Переносится типографика и цвета (шрифт, размер, цвет текста/ника, фон,
скругление, отступы, обводка, выравнивание); анимации и HTML-эффекты — нет.
Подробная таблица соответствия свойств, схема собственного JSON и ограничения:
[docs/THEMES.md](docs/THEMES.md).

## Что уже умеет

- **Twitch IRC** через WebSocket (`wss://irc-ws.chat.twitch.tv`), анонимно или
  с вашим OAuth-токеном.
- **Смайлы**: нативные Twitch (по тегу `emotes`), BTTV (глобальные + канальные),
  7TV (глобальные + канальные). Картинки качаются в фоне и кэшируются в памяти.
- **Бейджи** сабов/модеров/вайпов через Helix API (нужен Client-ID + OAuth).
- **Оформление**: шрифт, размер, жирность/курсив, цвет текста, цвет ника
  (с учётом цвета из IRC), фон панели со скруглением, обводка, масштаб смайлов.
- **Разметка**: привязка к любому углу источника, отступы, ширина блока,
  выравнивание, лимит сообщений, время жизни, плавное исчезновение.
- **Модерация**: скрытие команд, ссылок, капса, стоп-слов, игнор-лист юзеров.
- **Импорт дизайна**: пресеты, экспорт оверлея StreamElements, CSS из
  StreamElements/Streamlabs, собственный JSON-формат темы.
- **HTTP-прокси** для всех запросов (актуально, если Twitch/BTTV/7TV доступны
  только через прокси).

Вся отрисовка — собственная (Direct2D + DirectWrite + WIC), без Qt и без
внешних зависимостей: одна DLL.

## Установка

Нужен только готовый архив (собирается в GitHub Actions, см. ниже).

1. Скачайте `obs-chat-overlay-windows-x64.zip`.
2. Распакуйте в папку OBS Studio (обычно `C:\Program Files\obs-studio`),
   сохранив структуру:

   ```
   obs-studio\
     obs-plugins\64bit\obs-chat-overlay.dll
     data\obs-plugins\obs-chat-overlay\locale\en-US.ini
   ```

   Если OBS установлен в `Program Files`, архив нужно распаковывать
   от имени администратора.
3. Перезапустите OBS. В логе (`Справка → Файлы журнала`) должна появиться
   строка `[chat-overlay] loaded`.
4. В сцене: `+ → Chat Overlay`.
5. В свойствах источника укажите канал и (по желанию) ключи.

Для OBS 33+ плагин ставится в те же «legacy» папки; поддержка старого
расположения сохраняется до OBS 34.

## Настройка доступа к Twitch

Работает и без ключей: чат читается анонимно, смайлы Twitch/BTTV/7TV
подтягиваются. Без ключей **не будет бейджей** и канальных смайлов 7TV/BTTV
(для них нужен числовой ID канала, который берётся из Helix).

Чтобы включить всё:

1. **Client-ID**: <https://dev.twitch.tv/console/apps` → Register Your
   Application (OAuth Redirect URL: `http://localhost`, Category: Chat Bot) →
   скопируйте Client ID.
2. **OAuth-токен**: проще всего через сторонний генератор, например
   <https://twitchtokengenerator.com> (нужны scopes `chat:read`; для бейджей
   достаточно `user:read:email` не требуется). В поле «OAuth-токен» можно
   вставлять как `oauth:xxxxx`, так и просто `xxxxx`.
3. **Логин**: имя аккаунта, которому принадлежит токен (нужно IRC для `NICK`).

Токен хранится в настройках сцены OBS в открытом виде — как и у большинства
плагинов; не публикуйте файл сцены.

## Настройки источника

| Группа | Параметр | Описание |
| --- | --- | --- |
| Подключение | Канал Twitch | логин канала (без `#`) |
| | Логин / OAuth / Client-ID | см. выше |
| | TLS | выключение переводит IRC на незашифрованный порт 80 |
| | HTTP-прокси | `127.0.0.1:7890` и т.п., применяется ко всем запросам |
| Внешний вид | Шрифт, размер, жирный, курсив | системные шрифты Windows |
| | Цвет текста / ника / фона / обводки | с альфа-каналом |
| | Скругление, отступ текста | геометрия плашки |
| | Толщина обводки | 0 — без обводки |
| | Масштаб смайлов | относительно высоты строки |
| | Бейджи, ник | включение элементов |
| Разметка | Ширина/высота источника | «холст» плагина, масштабируется трансформом OBS |
| | Ширина блока чата | максимальная ширина строки |
| | Максимум сообщений | 1–60 |
| | Время жизни, мс исчезновения | 0 = сообщения не удаляются |
| | Привязка, отступы, выравнивание | положение внутри источника |
| Модерация | Команды, префиксы | по умолчанию `!` |
| | Ссылки | `http://`, `https://`, `www.`, `discord.gg/`, `t.me/`, `youtu.be/`, `clips.twitch.tv/` |
| | Порог капса | % заглавных при ≥10 буквах |
| | Стоп-слова | через запятую, с учётом границ слова |
| | Игнор-лист | логины через запятую |
| Смайлы | Twitch / BTTV / 7TV | по отдельности |

## Сборка

### Вариант 1. GitHub Actions (рекомендуется)

Подробная инструкция для тех, кто раньше не пользовался GitHub:
[docs/GITHUB.md](docs/GITHUB.md). Кратко:

1. Загрузите содержимое этой папки в новый публичный репозиторий на GitHub.
2. Вкладка **Actions → build → Run workflow**.
3. Через ~10–15 минут скачайте артефакт `obs-chat-overlay-windows-x64`
   (внутри — папки `obs-plugins/` и `data/`, готовые к копированию в OBS).

Workflow сам скачивает OBS-исходники и `obs-deps` нужных версий, собирает
плагин `RelWithDebInfo` и упаковывает его в структуру папок OBS.

### Вариант 2. Локально

Требуется Visual Studio 2022/2026 с C++ workload, CMake ≥ 3.28, git,
PowerShell 7 и интернет (скачиваются OBS-исходники и зависимости).

```powershell
pwsh -File .\build.ps1 -Configuration RelWithDebInfo
```

Результат: `release/RelWithDebInfo/` и `obs-chat-overlay-windows-x64.zip`.

Сборка использует каркас официального шаблона
[obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate)
(пин на конкретный коммит), поэтому `cmake/` и `CMakePresets.json`
подтягиваются автоматически и в репозитории не хранятся.

## Ограничения текущей версии

- Только Twitch. YouTube/Kick/VK — следующий этап (слой источников сообщений
  уже отделён от рендера, см. `src/twitch.cpp`).
- Анимированные смайлы (GIF) показываются первым кадром.
- Для смайлов используется `2x`-вариант картинки; на 4K-сценах качество
  может быть чуть мягче.
- Прокси поддерживает HTTP CONNECT-прокси (как у Clash/v2ray HTTP-порт);
  SOCKS5 напрямую в WinHTTP недоступен — используйте локальный HTTP-порт.
- Один источник = одно подключение к чату. Несколько источников на один канал
  лучше не добавлять (Twitch ограничивает число подключений к IRC).

## Архитектура

```
src/
  plugin-main.cpp   регистрация obs_source, свойства, жизненный цикл, вывод текстуры
  twitch.cpp        поток сети: IRC-over-WS, Helix (бейджи), BTTV/7TV (смайлы)
  chat.cpp          модель сообщений, парсер IRC-тегов, модерация, UTF-8/UTF-16
  images.cpp         фоновые загрузки картинок + декодирование через WIC
  render.cpp         вёрстка строк (DirectWrite) и растеризация панели (Direct2D)
  json.cpp           минимальный JSON-парсер (без зависимостей)
  net.cpp            WinHTTP: GET + WebSocket-клиент с поддержкой прокси
```

Поток данных: `TwitchWorker` (сеть) → очередь → `video_tick` (модерация) →
`ChatRenderer` (вёрстка/растеризация, только при изменениях) → `gs_texture` →
`obs_source_draw`. Тяжёлая работа (сеть, декодирование картинок) вынесена в
фоновые потоки; на видеопотоке — только композиция.

## Проверка после сборки

Пошаговый чек-лист «загрузил в GitHub → получил артефакт → поставил в OBS →
увидел чат», с точными строками лога и таблицей типичных сбоев:
[docs/VERIFY.md](docs/VERIFY.md).

В свойствах источника есть переключатель **«Подробный лог»** — он печатает
в лог OBS сырой IRC-трафик и ошибки Helix, это первое, что нужно включить при
разборе проблем.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Плагин не появился в списке | DLL лежит в `obs-plugins\64bit`, в логе есть `[chat-overlay] loaded` |
| Панель пустая, ошибок нет | не задан канал; проверьте `JOIN` в логе (уровень «Информация») |
| «disconnected, reconnecting» | блокировка Twitch/провайдером — задайте HTTP-прокси |
| Бейджей нет | нужны Client-ID + OAuth, иначе Helix недоступен |
| Смайлы — квадратики-плейсхолдеры | не скачались картинки: прокси, блокировка CDN, см. лог |
| Текст размытый | уменьшайте не источник, а размер шрифта (источник рендерится 1:1) |
