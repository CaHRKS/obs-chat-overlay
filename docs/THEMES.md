# Темы: импорт дизайна из StreamElements и Streamlabs

В плагине есть отдельная группа настроек **«Тема и импорт»**. Она умеет
принимать дизайн из трёх источников и переносить его в настройки внешнего вида
(шрифт, цвета, фон, обводка, отступы, выравнивание).

Важно понимать рамки: StreamElements и Streamlabs рисуют чат браузерным
HTML/CSS, а плагин рисует нативно. Поэтому переносится **стиль** (типографика,
цвета, плашка), но не разметка, анимации и произвольные HTML-эффекты.

---

## 1. Готовые пресеты

Самый быстрый путь. В свойствах источника:

**Тема и импорт → Готовый пресет** → выбери один из:

| Пресет | Что делает |
| --- | --- |
| `StreamElements — классика` | белый жирный текст, тень-обводка, без плашки |
| `Пузырьки` | скруглённая полупрозрачная плашка, обычное начертание |
| `Тёмная панель` | тёмный фон, светлый текст, тонкая обводка |
| `Чистый (без плашки)` | крупный текст без фона и обводки |

Нажми **Применить** — значения подставятся в настройки «Внешнего вида»
и сохранятся в сцене.

## 2. Импорт оверлея StreamElements (JSON)

StreamElements хранит оверлей как JSON: `widgets[]`, у каждого виджета есть
объект `css` с ключами вроде `font-family`, `font-size`, `color`,
`text-shadow`, вложенными `message` и `highlights`.

Как получить файл:

1. Открой **streamelements.com → Dashboard → Streaming Tools → Overlays**.
2. Выбери оверлей с чатом → меню **«…»** у оверлея → пункт скачивания/экспорта
   JSON (в разных версиях редактора он называется `Download`, `Export` или
   `Save as file`). Сохрани файл на диск.
3. В OBS: **Файл темы** → **Обзор…** → выбери этот `.json`.
4. **Применить**.

Плагин найдёт виджет чата (по `type`, содержащему `chat`, либо по наличию
`css.message`) и возьмёт его стиль.

> Если в твоей версии редактора нет экспорта — используй способ 3 (CSS):
> он работает всегда.

## 3. Вставка CSS (универсальный способ)

Подходит для StreamElements и Streamlabs, а также для любых готовых тем,
которые распространяются как CSS.

1. В StreamElements открой виджет чата → **Settings → Custom CSS** (вкладка
   `CSS`).
2. Скопируй блок целиком, например:

   ```css
   .message {
     font-family: 'Roboto', sans-serif;
     font-size: 28px;
     color: #ffffff;
     background-color: rgba(0, 0, 0, 0.55);
     border-radius: 12px;
     padding: 8px;
     text-shadow: rgba(0, 0, 0, 0.9) 1px 1px 2px;
   }
   ```

3. В OBS вставь этот текст в поле **«Вставить CSS из StreamElements /
   Streamlabs»**.
4. **Применить**.

Скрипт разбирает все объявления `свойство: значение;` в блоках `{ … }`
и применяет последнее встреченное значение.

## 4. Что переносится

| CSS-свойство | Настройка плагина | Примечание |
| --- | --- | --- |
| `font-family` | Шрифт | берётся первое семейство; шрифт должен быть установлен в Windows |
| `font-size` | Размер шрифта | `px`, `pt`, `em/rem` приводятся к px |
| `font-weight` | Жирный | `bold`, `bolder` или ≥ 600 |
| `font-style` | Курсив | `italic` / `oblique` |
| `color`, `text-fill-color` | Цвет текста | `#rgb`, `#rrggbb`, `#rrggbbaa`, `rgb()`, `rgba()`, базовые имена |
| `background-color`, `background` | Фон панели | цвет извлекается из сокращённой записи |
| `border-radius` | Скругление фона | px |
| `padding` | Отступ текста от края | первое значение |
| `-webkit-text-stroke`, `-webkit-text-stroke-width/-color` | Обводка | толщина + цвет |
| `text-shadow` | Обводка 1 px | если обводка не задана явно — берётся цвет тени |
| `text-align` | Выравнивание | left / center / right |
| `line-height` | Отступ между сообщениями | приблизительно, `×0.35` |
| `highlights.color` (в JSON SE) | Цвет ника (если Twitch не задал) | эвристика |

## 5. Что не переносится

- анимации, `@keyframes`, переходы, `transform`;
- градиенты и картинки на фоне (`background: url(...)`) — плагин оставит
  только цвет, если он есть в записи;
- CSS-переменные (`--color`) и каскад с разными стилями для разных элементов:
  у плагина один стиль текста и один стиль ника;
- отдельные стили для бейджей и смайлов;
- веб-шрифты `@import` — шрифт нужно установить в систему.

## 6. Свой JSON-формат

Можно написать тему руками или поправить импортированную. Схема — плоский
набор необязательных полей:

```json
{
  "name": "my-theme",
  "font": { "face": "Roboto", "size": 30, "bold": true, "italic": false },
  "colors": {
    "text": "rgba(255, 255, 255, 1)",
    "nick": "#8ab4f8",
    "background": "rgba(0, 0, 0, 0.55)",
    "outline": "#000000"
  },
  "outline": 2,
  "radius": 12,
  "padding": 8,
  "line_spacing": 6,
  "emote_scale": 1.0,
  "align": "left"
}
```

Незаданные поля игнорируются — текущее значение настройки сохраняется.

## 7. Правила срабатывания

- Импорт выполняется **один раз** при изменении: выбран другой пресет,
  указан другой файл, изменился вставленный CSS.
- После импорта плагин **не перезаписывает** твои ручные правки: можно
  спокойно менять цвет, размер и отступы дальше.
- Чтобы применить тот же пресет повторно (например, после экспериментов),
  переключи пресет на «Не применять», нажми «Применить», затем выбери пресет
  снова.
- В лог OBS пишется `[chat-overlay] theme applied (…)` и причина отказа,
  если файл или CSS не разобрались.

## 8. Ограничения и планы

- Нет живой синхронизации с сервисом (StreamElements API требует JWT и
  сетевого доступа; сейчас импорт — по файлу или CSS). Если нужно — добавим
  отдельным шагом: `theme_url` + фоновое обновление.
- Не поддерживаются SOCKS-прокси для загрузки тем: импорт локальный, сеть не
  используется.
