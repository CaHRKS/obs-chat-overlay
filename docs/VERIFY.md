# Проверка сборки и плагина в OBS

Пошаговый чек-лист: от загрузки исходников в GitHub до первого сообщения чата
на экране. Рассчитан на то, что сборку делает CI, а запуск — на твоей машине.

---

## 1. Загрузить проект в GitHub

1. Создай **пустой** репозиторий (без README/.gitignore), например
   `obs-chat-overlay`.
2. Загрузи содержимое папки `obs-chat-overlay/` в корень репозитория так, чтобы
   структура была:

   ```
   CMakeLists.txt
   buildspec.json
   src/...
   data/...
   .github/workflows/build-windows.yml
   ```

   Через веб-интерфейс: `Add file → Upload files`, перетащить всё содержимое
   папки (не саму папку). Через git:

   ```powershell
   git init
   git add .
   git commit -m "chat overlay plugin"
   git branch -M main
   git remote add origin https://github.com/<логин>/obs-chat-overlay.git
   git push -u origin main
   ```

## 2. Запустить сборку

1. Вкладка **Actions** → workflow **build** → **Run workflow** → `main` → Run.
2. Ждать 10–20 минут (шаг `Configure` качает OBS-исходники и `obs-deps` —
   он самый долгий).
3. Успех = зелёная галочка и артефакт `obs-chat-overlay-windows-x64` внизу
   страницы запуска.

**Если упало** — скачай лог упавшего шага (`⋯ → Download log`) или пришли
последние 40–60 строк: этого достаточно, чтобы я поправил код.

## 3. Установить в OBS

1. Скачай артефакт, распакуй `obs-chat-overlay-windows-x64.zip`.
2. Внутри — две папки: `obs-plugins` и `data`. Скопируй их **в папку OBS**
   с заменой:

   ```
   C:\Program Files\obs-studio\obs-plugins\64bit\obs-chat-overlay.dll
   C:\Program Files\obs-studio\data\obs-plugins\obs-chat-overlay\locale\...
   ```

   Для записи в `Program Files` нужны права администратора. Портативный OBS —
   просто скопировать в его корень рядом с `obs64.exe`.
3. Полностью перезапусти OBS (не просто закрыть окно — выйти из трея).

## 4. Проверить по логу

`Справка → Файлы журнала → Посмотреть текущий журнал`. Ищи строки
(в порядке появления):

| Строка в логе | Что означает |
| --- | --- |
| `[chat-overlay] loaded, source id obs_chat_overlay` | DLL загрузилась, плагин зарегистрирован |
| `[chat-overlay] starting worker for #канал` | источник создан и запустил сеть |
| `[chat-overlay] worker start: channel=... tls=1 ...` | поток стартовал, параметры прочитаны |
| `[chat-overlay] connecting to wss://irc-ws.chat.twitch.tv:443` | идёт подключение |
| `[chat-overlay] websocket open` | TLS и WebSocket поднялись |
| `[chat-overlay] room-id from IRC: 898594323` | номер канала получен без ключей (нужен для канальных бейджей и смайлов) |
| `[chat-overlay] channel id 123456` | id канала подтверждён через Helix (если заданы ключи) |
| `[chat-overlay] badges from ivr.fi mirror: N` | бейджи (включая сабов) получены без ключей — основной путь |
| `[chat-overlay] badges from public API: N` | резервный источник без ключей |
| `[chat-overlay] badges from Helix: N` | источник с Client-ID/OAuth |
| `[chat-overlay] badge APIs unavailable: ...` | все публичные источники недоступны — останутся встроенные глобальные бейджи |
| `[chat-overlay] emotes loaded: N` | смайлы BTTV/7TV загружены (канальные — тоже без ключей) |
| `[chat-overlay] first message received from ...` | **чат пошёл** |
| `[chat-overlay] image failed: ...` | картинка смайла/бейджа не скачалась (видно в подробном логе) |

Если строк нет или они обрываются — смотри следующий раздел.

## 4b. Проверка без сети (канал оффлайн)

Если канал оффлайн, сообщений не будет и проверить отрисовку нечем. Два способа:

**Быстро (без пересборки):** в свойствах источника укажи в поле «Канал Twitch»
любой **живой** канал (например, `twitch` или популярный стрим), нажми
«Применить» — чат пойдёт, можно проверить шрифт, цвета и смайлы. Потом верни
свой канал.

**Правильно:** включи **Диагностика → «Демо-режим: тестовые сообщения без
сети»** и нажми «Применить». Плагин раз в 1,5 секунды добавляет локальные
сообщения и не подключается к Twitch вообще:

| № | Что проверяет |
| --- | --- |
| 1 | обычный текст, цвет ника, шрифт, обводка |
| 2 | смайлы Twitch (Kappa, PogChamp, LUL, 4Head, BibleThump) |
| 3 | перенос длинной строки по словам |
| 4 | бейджи модератора и Prime |
| 5 | `/me`-сообщение (без двоеточия после ника) |
| 6–8 | три сообщения, которые должна скрыть модерация (команда, капс, ссылка) |

В логе появится `[chat-overlay] demo mode enabled: local test messages, no
network`. Выключи демо-режим и нажми «Применить», чтобы вернуться к живому чату.

## 5. Проверить визуально

1. `Источники → + → Chat Overlay`.
2. В свойствах укажи канал (логин, без `#`).
3. Напиши что-нибудь в чат канала (или дождись сообщения).
4. Проверь по очереди:
   - панель видна, текст читается на фоне игры;
   - ник окрашен в цвет Twitch;
   - длинное сообщение переносится по словам, а не уезжает за край;
   - смайлы `Kappa` / `KEKW` рисуются картинками, а не текстом;
   - бейджи саба/модера слева от ника;
   - при `Время жизни = 30` старое сообщение плавно исчезает;
   - при `!команда` в чате сообщение не появляется (модерация команд);
   - тема: выбрать пресет **«Пузырьки»** → **Применить** → появилась
     полупрозрачная скруглённая плашка (в логе `theme applied (preset …)`).

## 6. Если что-то не так

Включи в свойствах источника **«Подробный лог»**, повтори действие и собери:

1. лог OBS (файл целиком или фрагмент `[chat-overlay]`);
2. как настроен источник (скриншот вкладки свойств);
3. что видно на превью.

Типичные причины:

| Симптом | Причина / что делать |
| --- | --- |
| нет строки `loaded` | DLL не в `obs-plugins\64bit` или OBS не перезапущен |
| панель пустая, в логе спам `obs_source_draw: no active effect` | старая версия плагина (1.0.0). Обнови DLL до 1.0.1+ — рисование переведено на собственный effect loop |
| `websocket handshake failed` | Twitch недоступен напрямую — задай HTTP-прокси в свойствах |
| `websocket open`, но нет сообщений | не тот канал (или канал офлайн); проверь `JOIN` в подробном логе |
| `cannot resolve channel id` | неверный Client-ID/токен; без них бейджи отключены |
| сообщения «пропадают», особенно капсом | включён фильтр капса: **Модерация → Порог капса → 0** (в 1.0.2 по умолчанию выключен) |
| сообщения есть, смайлов нет | картинки не скачались — прокси/блокировка CDN, см. `helix ... failed` и повторы |
| текст мыльный | источник отрендерен 1:1, уменьшай не трансформом, а размером шрифта |

## 7. Что прислать мне

- лог упавшего шага CI (если не собралось);
- фрагмент лога OBS с `[chat-overlay]` (если собралось, но не работает);
- скриншот превью.

По логу видно, на каком слое проблема: загрузка DLL, TLS, IRC, Helix или
рендер — правки будут точечными.
